**Goal:** Finish the Comment→Proposal rename inside `108jobs-clean`'s `108jobs-client` package and its consumers, correcting the four live wire-contract bugs the drift caused.

**Tech Stack:** TypeScript, Next.js 16, pnpm, a hand-maintained `file:` package at `src/lib/108jobs-client`.

**Spec:** `docs/superpowers/specs/2026-08-17-client-comment-to-proposal-rename-design.md`
